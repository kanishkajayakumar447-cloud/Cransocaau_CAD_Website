# Cransocaau | CAD Design Training Institute

A modern, responsive **CAD Design Training Institute website** built using HTML, CSS, and JavaScript.

The website is designed to help students explore CAD courses, assess their interests, compare courses, view training information, and connect with the institute.

## 🌐 Website Features

* 📚 CAD course showcase
* 🔎 **Find Your CAD Course** recommendation
* 📝 **10-question CAD skill assessment**
* 🧊 3D/project gallery
* ⚖️ Course comparison
* 👨‍🏫 Trainer profiles
* 💼 Career and placement support section
* 📱 Responsive design for mobile, tablet, and desktop
* 💬 WhatsApp enquiry integration
* ❓ FAQ section with search
* 🌙 Dark/Light mode
* 📋 Course details modal
* 📍 Institute/location information
* 📄 Brochure/enquiry support
* 🎯 Student-focused course navigation

## 🛠️ Technologies Used

* **HTML5** – Website structure and content
* **CSS3** – Styling, layout, responsiveness, and themes
* **JavaScript** – Interactive features and functionality
* **Google Fonts** – Poppins typography
* **Git & GitHub** – Version control and deployment
* **GitHub Pages** – Website hosting

The website includes a **10-question assessment** that helps visitors identify a suitable CAD learning path based on their answers.

The assessment is implemented using JavaScript and runs directly in the browser without requiring a backend.

## 🚀 Run Locally

1. Download or clone this repository.

2. Open the project folder.

3. Make sure `index.html`, `style.css`, and `script.js` are in the correct locations.

4. Open `index.html` in a browser.

For development, you can also use **VS Code with Live Server**.

## 🌐 GitHub Pages Deployment

To deploy the website using GitHub Pages:

1. Upload the project files to your GitHub repository.
2. Make sure the homepage is named:

```text
index.html
```

3. Open:

**Repository → Settings → Pages**

4. Under **Build and deployment**, select:

```text
Deploy from a branch
```

5. Select:

```text
main
/
(root)
```

6. Click **Save**.

After deployment, GitHub Pages will provide the live website URL.

## 🔄 Updating the Website

When making changes:

1. Update the required HTML, CSS, or JavaScript files.
2. Upload/replace the files in the GitHub repository.
3. Commit the changes.
4. Wait for GitHub Pages to rebuild the website.
5. Refresh the live website.

If the old version appears, perform a hard refresh:

```text
Ctrl + F5
```
