# Cransocaau | CAD Design Training Institute

A GitHub Pages-ready static website built with:

- HTML
- CSS
- JavaScript
- Responsive layout
- Course finder
- 10-question skill assessment
- Project gallery filters
- Course comparison
- Trainer profiles
- Career journey
- WhatsApp enquiry
- FAQ search
- Dark/light mode
- Course details modal

## Files

- `index.html`
- `style.css`
- `script.js`

## GitHub Pages

Upload all three files to the root of a GitHub repository.

Then go to:

Settings → Pages → Deploy from a branch → `main` → `/ (root)`

The homepage must remain named `index.html`.

## Before launch

Replace placeholder trainer, address, WhatsApp number, statistics, testimonials and other demo content with verified client information.
