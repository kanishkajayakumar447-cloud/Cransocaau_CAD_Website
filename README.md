# Cransocaau — Professional CAD Design Training Institute

A modern, responsive website concept for a CAD Design Training Institute, designed to present training programs, learning resources, project showcases, and course enquiry options through a polished user interface.

## 🌟 Project Overview

**Cransocaau** is a front-end website project built to demonstrate a professional online presence for a CAD training institute. It helps visitors explore available courses, understand training options, browse project examples, assess their interests, and enquire about training.

The homepage features a **split-layout hero section**, with introductory text and call-to-action buttons on the left and a creative visual on the right.

## ✨ Key Features

- **Modern Hero Section** — Split layout with introductory content, a supporting image, and prominent action buttons.
- **Responsive Navigation** — Navigation links to the main sections of the website.
- **CAD Course Listings** — Course cards for CREO, SolidWorks, CATIA, and AutoCAD.
- **Course Finder** — Helps visitors explore courses based on their goals, experience, and interests.
- **Interactive Skill Assessment** — Course selection and a 10-question multiple-choice assessment interface.
- **Training Options** — Dedicated sections for online and offline learning.
- **Project Showcase** — Example engineering design projects presented in a card layout.
- **3D Project Gallery** — Gallery items with software-based filtering.
- **Course Comparison** — Interface for comparing available CAD programs.
- **Trainer Profiles** — Sections highlighting trainer information and areas of expertise.
- **Career Preparation** — Content covering resume building, mock interviews, portfolio development, and career guidance.
- **Course Brochure** — Downloadable brochure section.
- **WhatsApp Enquiry** — Quick enquiry options for visitors interested in training.
- **FAQ Search** — Searchable frequently asked questions.
- **Student Testimonials** — A section for displaying learner feedback.
- **Contact Form** — Form interface for course enquiries.
- **Responsive Design** — Designed to support different screen sizes.
- **Visual Theme** — A refined burgundy, plum, rose, and light pastel colour palette.

## 🛠️ Technologies Used

- **HTML5** — Website structure and content.
- **CSS3** — Layout, styling, colours, and responsive design.
- **JavaScript** — Interactive website components and user interactions.
